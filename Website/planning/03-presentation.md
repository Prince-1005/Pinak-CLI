# Phase 3 — Product presentation

## Inputs and dependencies

Phase 1 shared shell, Phase 2 manifest, real screenshots, and implemented CLI behavior.

## Tasks and outputs

- Build the terminal-studio visual language with charcoal, cyan, amber, Inter, and JetBrains Mono.
- Compose hero, first-use walkthrough, alternating feature narratives, screenshot showcase, local-operation explanation, and final installation CTA.
- Frame screenshots attractively without destroying their source or cropping the full viewer.
- Add social preview, favicon, canonical metadata, about page, changelog, and helpful 404.
- Clearly label illustrative terminal output and distinguish it from actual captures.

## Commands

`npm run dev`, `npm run build`, `npm run test:browser`.

## Acceptance

A new visitor understands the toolkit and can find installation in one interaction. Real screenshots are readable in the viewer. No fabricated customer counts, testimonials, platform guarantees, or unreleased product claims appear. Layouts have no horizontal overflow at mobile widths.

## Completion notes

Product sections favor editorial layouts over repeated generic cards. Media serves the explanation. Unsupported source or terminal conditions are acknowledged in relevant guides.
