Pinak is a Python command-line media toolkit built around **yt-dlp** and **FFmpeg**. Download supported media, extract audio, inspect local history, and play local video, audio, and pictures.

## Get started

```sh
pipx install pinak-cli
pinak --version
pinak --doctor
```

Python 3.10 or newer is required. [Start with platform-specific setup](./installation/), including pipx installation, if these commands are not available yet.

## Make your first download

Replace the placeholder with a supported HTTP(S) URL. Only download media you own or have permission to save.

```sh
pinak "<your-media-url>"
pinak "<your-media-url>" --audio
pinak "<your-media-url>" --quality 720p -o downloads
```

Run `pinak` alone for the interactive shell. Use `pinak media <local-path>` to open local media.

## Connect your AI application

[Choose Local or Cloud MCP](./mcp/) to manage the durable download queue from a compatible AI application. Local stdio stores files on your device; user-hosted Cloud stores them on your own server and provides expiring download links. Pinak runs no shared hosting service.

## What local means

The installed package runs on your device. Downloads connect to their sources and are saved to your output directory. Pinak does not use a shared cloud download backend. Settings and history are local; source availability and network access still matter.

These guides follow the current source and operating guide. The PyPI release may differ from repository source; check `pinak --version`.
